## 1. Context & Stage 8.14A Findings

Stage 8.14A Residual Error Forensics established the following empirical observations on the frozen Stage 8.1 Operational Champion ($28.0688\%$ daytime nMAE, $36.19\text{ W/m}^2$ MAE, $64.22\text{ W/m}^2$ RMSE):

1. **Error Tail Concentration**: $11.17\%$ of daytime forecast hours with $|error| > 100\text{ W/m}^2$ account for **49.84% of total daytime absolute error**. Median absolute error is low ($13.14\text{ W/m}^2$).
2. **Solar Elevation Concentration**: High solar elevation hours ($30^\circ - 50^\circ$) drive **44.68% of total daytime absolute error** because high solar amplitude allows large absolute deviations when cloud state is mispredicted.
3. **Cloud Regime Concentration**: Intermediate-cloud / partial-cloud regimes ($10\% - 90\%$ cloud cover) contain **55.55% of total daytime error** and exhibit high instantaneous-error variance. Retrospective top-50 event analysis shows 22/50 events (44%) are consistent with missed clearing events (over-clouded NWP forecast).
4. **Temporal Persistence**: Residual lag-1 autocorrelation across valid daytime hours is **0.5863**, consistent with multi-hour forecast-state or cloud-arrival timing errors.

## 4. Candidate Information Families to Investigate

Stage 8.14B must systematically audit observational data sources across candidate families without assuming any single family is automatically the answer:

- **Family A: Ground-based all-sky / sky-camera observations** (Local hemispheric cloud cover, cloud type, optical thickness at/near Abisko/Nuolja).
- **Family B: Ground-based cloud-base / ceilometer observations** (Cloud base height, vertical cloud layering, optical backscatter profiles).
- **Family C: Ground-based radiometer / pyranometer decomposition** (Direct/diffuse radiation split, real-time clearness index $K_t$ upwind/local).
- **Family D: Satellite cloud-mask observations** (EUMETSAT / VIIRS / MODIS spatial cloud presence/absence grids).
- **Family E: Satellite cloud-motion observations** (Satellite-derived cloud motion vectors, advection velocity).
- **Family F: Satellite cloud optical properties** (Cloud Optical Thickness [COT], Cloud Effective Radius [CER], Cloud Top Pressure [CTP], Cloud Phase).

## 5. Required 20-Point Feasibility Evaluation Criteria

For **EVERY** candidate observational data source, Stage 8.14B must audit and document all 20 criteria:

1. **Exact Product/Dataset Name:** Formal catalog name and version.
2. **Provider / Dissemination Body:** Agency or organization (e.g. EUMETSAT, SMHI, NASA Earthdata, Copernicus).
3. **Exact Variables Included:** Precise physical quantities provided.
4. **Spatial Resolution:** Native grid pixel size at $68.35^\circ\text{N}$.
5. **Temporal Resolution:** Repeat frequency or update cadence.
6. **2024 Historical Availability:** Complete 2024 calendar coverage match with SITES/NWP baseline.
7. **Empirical Coverage at/near Nuolja:** Pixel validity and sensor view angle at Nuolja coordinates ($68.358^\circ\text{N}, 18.783^\circ\text{E}$).
8. **Acquisition Timestamp ($t_{acq}$):** Exact physical sensor measurement timestamp.
9. **Publication / Dissemination Timestamp ($t_{pub}$):** Exact timestamp when product file becomes accessible on public/operational servers.
10. **Causal Availability Relative to Forecast Origin $t_0$:** Absolute requirement: $t_{pub} < t_0$. Physical acquisition time $t_{acq}$ is NOT sufficient if publication lag delays availability past $t_0$.
11. **Polar-Night / Low-Sun Behavior:** Product validity during Arctic low solar elevation ($< 10^\circ$) and winter darkness.
12. **Viewing Geometry & Representativeness:** Parallax error, satellite slant angle, terrain occlusion.
13. **Distance from Nuolja Station:** Spatial proximity of nearest valid observation point.
14. **Observational vs Modeled Nature:** Does the product measure actual physical radiance/backscatter, or is it an NWP model reanalysis output?
15. **Information Novelty Relative to Stage 8.1:** Does it contain non-redundant information beyond $\{ \text{NWP cloud\_cover}, \text{LWP}, \text{IWP}, U_{700}, V_{700} \}$?
16. **Reconciliation with Closed Routes:** Has an equivalent product or route already been evaluated and closed?
17. **Missing-Data & Outage Rate:** Percentage of missing, corrupt, or flagged null pixels across 2024.
18. **Full H1–H24 Experiment Feasibility:** Can this product support complete 24-hour ahead operational execution?
19. **Preservation of Locked Benchmark:** Does integration preserve the exact SITES ground truth evaluation protocol?
20. **Operational Reproducibility for 2024:** Can the data pipeline be programmatically reproduced in Python?
