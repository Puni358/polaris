POLARIS STAGE 4.3 — DYNAMIC BLENDING EXPERIMENT SUMMARY
================================================================================

HYPOTHESIS:
  The optimal blend between Chronos and Physics forecasts is state-dependent
  rather than fixed solely by horizon.

APPROACH:
  Delta-parameterized logistic blender with 10 forecast-time features:
    logit(w_dynamic) = logit(w_stage4_h) + X_scaled @ theta
    P_dynamic = w_dynamic * P_chronos + (1 - w_dynamic) * P_physics

TRAINING:
  - 174 EVEN origins (2024-01-20, 01-22, ..., 12-31)
  - 2,885 daytime samples
  - Forward-chaining 4-fold CV
  - Ridge regularization (λ = 100.0)
  - Huber loss (δ = 10 W/m²)

TEST SET (173 ODD ORIGINS, DAYTIME):
  Stage 4:   MAE = 43.451 W/m², nMAE = 33.70%
  Stage 4.3: MAE = 43.463 W/m², nMAE = 33.71%
  
  Δ MAE = +0.012 W/m² (+0.03%) — DEGRADATION

STATISTICAL SIGNIFICANCE:
  - Bootstrap 95% CI: [-0.055, +0.063] W/m²
  - Paired t-test: p = 0.9791 (not significant)
  - Conclusion: No measurable improvement

WEIGHT DIAGNOSTICS:
  - Dynamic weights nearly identical to Stage 4 fixed weights
  - Mean: 0.4361 vs 0.4345 (Stage 4)
  - Std: 0.2628 vs 0.2633 (Stage 4)
  - Model essentially reproduced horizon-specific baseline

FEATURE IMPORTANCE:
  All coefficients very small (|θ| < 0.05):
    - cloud_frac: -0.042 (strongest)
    - clearsky_x_clearfrac: +0.022
    - Other features: < 0.01
  
  Interpretation: Weak state-dependent signal

PER-HORIZON:
  - Improved: 2 / 24 horizons
  - Degraded: 3 / 24 horizons
  - Neutral: 19 / 24 horizons

MULTICOLLINEARITY WARNING:
  - Condition number: 1694.3 (high)
  - solar_elevation ↔ clearsky_ghi: r = 0.981
  - ctx_mean ↔ ctx_std: r = 0.969
  - Features contain redundant information

DECISION: **REJECT STAGE 4.3**

REASONING:
  1. No improvement over Stage 4 baseline
  2. Features lack sufficient state-dependent signal
  3. Stage 4's horizon-adaptive weights already capture dominant pattern
  4. Multicollinearity dilutes predictive power
  5. ~35% of samples have components agreeing within 10 W/m²
