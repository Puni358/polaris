# POLARIS — G1.3-E THRESHOLD ARCHITECTURE ALTERNATIVES EVALUATION

## Executive Summary

This report evaluates six candidate architectural options for telemetry freshness evaluation in POLARIS, fulfilling **Research Dimension 12** and addressing the **Critical Question** of timestamp age vs. state uncertainty tolerance.

---

## 1. EVALUATION OF THE SIX CANDIDATE THRESHOLD ARCHITECTURES

### Option A: Universal Fixed Age
- **Description**: A single static numerical threshold (e.g., $\Delta t_{\text{max}} = 300\text{ s}$) applied uniformly across all generators and measurement types.
- **Scientific Defensibility**: **LOW / INDEFENSIBLE.** Fails to account for rate of change variations ($\frac{dx}{dt}$) spanning 4 orders of magnitude.
- **Implementation Complexity**: Very Low.
- **Failure Coverage**: Poor. Misses fast generator trips ($< 1\text{ s}$) while causing false invalidations for slow fuel telemetry during minor network drops.
- **POLARIS Recommendation**: **REJECTED** (Explicitly prohibited by Human Decision G1.3-E).

---

### Option B: Measurement-Specific Fixed Age
- **Description**: Distinct static time limits assigned to each measurement type (e.g., Generator State $\le 2\text{ s}$, Fuel Level $\le 900\text{ s}$).
- **Scientific Defensibility**: Moderate. Improves alignment with physical dynamics.
- **Implementation Complexity**: Low-Moderate.
- **Failure Coverage**: Moderate. Accounts for measurement type differences but ignores generator operating state (Running vs OFF).
- **POLARIS Recommendation**: **PARTIAL** (Acceptable as a fallback baseline, but incomplete).

---

### Option C: Resource-Specific Fixed Age
- **Description**: Static time limits customized per generator model and sensor hardware (e.g., Gen 1 Caterpillar C9 state $\le 1\text{ s}$, Gen 2 Cummins QSB state $\le 5\text{ s}$).
- **Scientific Defensibility**: Moderate-High. Respects specific sensor hardware capabilities and SCADA polling limits.
- **Implementation Complexity**: Moderate. Requires separate lookup tables per microgrid asset.
- **Failure Coverage**: Moderate-High.
- **POLARIS Recommendation**: **PARTIAL** (Acceptable as resource-specific baseline).

---

### Option D: State-Dependent Age
- **Description**: Telemetry freshness threshold adjusts dynamically based on the operational state of the generator ($u(t)$) and system emergency state.
  - *Running Generator ($u=1$)*: Power telemetry age $\le 5\text{ s}$.
  - *OFF Generator ($u=0$)*: Start-readiness telemetry age $\le 600\text{ s}$.
- **Scientific Defensibility**: High. Directly matches state-space physical requirements.
- **Implementation Complexity**: Moderate-High.
- **Failure Coverage**: High.
- **POLARIS Recommendation**: **RECOMMENDED FOR FURTHER STUDY**.

---

### Option E: Dynamic Uncertainty-Based Criterion
- **Description**: Replaces static age limits entirely with an **Uncertainty-Bounded State Criterion**. Telemetry remains valid if cumulative state error over 6-hour horizon satisfies:
  $$\sigma_{E_{\text{gen}}}(t_{\text{now}}, \Delta t_{\text{age}}) \le \epsilon_{\text{surv\_tolerance}}$$
- **Scientific Defensibility**: **VERY HIGH.** Mathematically rigorous; grounds freshness directly in survivability credit margin $M_{\text{surv}}$.
- **Implementation Complexity**: High (Requires real-time variance propagation model).
- **Failure Coverage**: Very High. Automatically tightens freshness bounds when survivability margin $M_{\text{surv}}$ is low, and relaxes them when battery reserves are abundant.
- **POLARIS Recommendation**: **HIGHLY RECOMMENDED AS TARGET FORMULATION**.

---

### Option F: Hybrid Criterion (Option E + Multi-Sensor Corroboration)
- **Description**: Combines Dynamic Uncertainty (Option E) with multi-sensor cross-validation (e.g., corroborating generator power with bus frequency, or fuel level with fuel flow integration).
- **Scientific Defensibility**: **EXEMPLARY.** Provides complete coverage against sensor failure, stuck SCADA buffers, and comms drops.
- **Implementation Complexity**: High.
- **Failure Coverage**: Complete.
- **POLARIS Recommendation**: **RECOMMENDED LONG-TERM TARGET ARCHITECTURE**.

## 3. DEEP DIVE ON THE CRITICAL QUESTION

### Static Timestamp Age ($\Delta t \le X$) vs. Uncertainty-Bounded State Criterion ($\sigma_{\text{state}} \le \epsilon$)

> **CRITICAL QUESTION**: Should a future G1.3-E rule be expressed as `"maximum telemetry age <= X"` or `"telemetry remains safety-eligible while uncertainty in the resource state remains below the survivability decision tolerance"`?

#### Research Conclusion:
The research conclusively establishes that the **Uncertainty-Bounded State Criterion ($\sigma_{\text{state}} \le \epsilon$)** is scientifically superior for the following reasons:

1. **Context Sensitivity**: Under static timestamp rules ($\Delta t \le 300\text{ s}$), a 6-minute-old fuel measurement is rejected even if battery SOC is $95\%$ and $M_{\text{surv}} > +100\text{ kWh}$. Under the uncertainty criterion, because $M_{\text{surv}}$ margin is high, the fuel uncertainty is well within decision tolerance, preventing unnecessary loss of generator credit.
2. **Emergency Tightening**: Conversely, when battery SOC drops to $25\%$ ($M_{\text{surv}} \to 0$), the uncertainty tolerance $\epsilon$ shrinks automatically, requiring ultra-fresh telemetry ($< 5\text{ s}$) before generator credit can be trusted. Static timestamp rules cannot adapt to system risk state.

#### Operationalization Requirements:
To operationalize Option E/F in a future implementation pass, POLARIS must define:
1. Open-loop state variance drift function $\sigma^2_x(\Delta t)$ for fuel, power, and block heater temperature.
2. System survivability risk tolerance $\epsilon_{\text{surv\_tolerance}}(M_{\text{surv}})$.
