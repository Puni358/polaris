# POLARIS — G1.3-E STANDARD, OEM, PROTOCOL & SOURCE CONTEXT AUDIT (MICRO-CORRECTED)

## Executive Summary

This document delivers a precise, source-by-source audit of all standards, protocols, manufacturer specifications, and operational logs cited in the G1.3-E research package.

---

## 1. INDIVIDUAL SOURCE CONTEXT AUDITS

### 1.1 IEEE Std 1547.4-2011 & IEEE 1547-2018
1. **What does the source actually specify?** Interconnection requirements, islanding transition protocols, breaker trip clearing times ($30–100	ext{ ms}$), and distributed resource control interfaces.
2. **Category**: Control & Interconnection Standard.
3. **Does it define telemetry freshness?** **NO.** It specifies trip response speed and interface protocols, not maximum allowable telemetry age for energy accounting.
4. **Does it apply to generator survivability?** Indirectly (provides breaker opening dynamics).
5. **Does it apply to polar microgrids?** No (general DER grid-interconnection focus).
6. **Does it justify a POLARIS safety-credit rule?** **NO.**
7. **Narrower legitimate claim**: IEEE 1547.4 establishes that physical circuit breaker opening occurs within $30–100	ext{ ms}$ following a trip command.

---

### 1.2 IEC 61850 & IEC 61850-7-420
1. **What does the source actually specify?** Substation automation communication architecture, logical nodes (`XCBR`, `MMXU`), timestamping rules, and data quality bitfields.
2. **Category**: SCADA Communication Protocol Standard.
3. **Does it define telemetry freshness?** **NO.** It defines how timestamps and quality flags are encoded in packets, NOT how old a packet may be before safety credit is lost.
4. **Does it apply to generator survivability?** Indirectly (data structure standard).
5. **Does it apply to polar microgrids?** No (generic power system communication standard).
6. **Does it justify a POLARIS safety-credit rule?** **NO.**
7. **Narrower legitimate claim**: IEC 61850 provides standard data attributes (timestamp, validity quality flag, CRC) required for Stage 1–3 telemetry validation.

---

### 1.3 SAE J1939-71 (ECU CAN-bus Protocol)
1. **What does the source actually specify?** Heavy-duty vehicle and industrial engine ECU CAN-bus message frames, Diagnostic Trouble Codes (DTCs), and periodic broadcast rates ($100	ext{ ms}/1000	ext{ ms}$).
2. **Category**: Industrial Diagnostics & Communication Protocol.
3. **Does it define telemetry freshness?** **NO.** Broadcast rates specify how often an ECU sends a packet, NOT how long POLARIS may trust a stale reading during a comms outage.
4. **Does it apply to generator survivability?** Indirectly (defines ECU diagnostic latching).
5. **Does it apply to polar microgrids?** No (heavy-duty engine focus).
6. **Does it justify a POLARIS safety-credit rule?** **NO.**
7. **Narrower legitimate claim**: SAE J1939 defines ECU fault code latching mechanisms and engine sensor message schemas.

---

### 1.4 NFPA 110 (Standard for Emergency & Standby Power Systems)
1. **What does the source actually specify?** Emergency generator start timing ($10	ext{ s}$ requirement for Class 10 systems), block heater coolant maintenance ($40^\circ	ext{C}$), and battery starter maintenance.
2. **Category**: Operational Safety & Emergency Power Standard.
3. **Does it define telemetry freshness?** **NO.** It specifies equipment maintenance and response speed requirements, NOT telemetry age thresholds.
4. **Does it apply to generator survivability?** Yes (defines standby start readiness requirements).
5. **Does it apply to polar microgrids?** Partial (general standby power focus).
6. **Does it justify a POLARIS safety-credit rule?** **NO (Justifies start-readiness concept, not numerical freshness).**
7. **Narrower legitimate claim**: NFPA 110 justifies requiring validated block heater temperature ($T_{	ext{block}} \ge 40^\circ	ext{C}$) and starter battery voltage before crediting an OFF generator under G1.2.

---

### 1.5 OSHA LOTO (29 CFR 1910.147)
1. **What does the source actually specify?** Hazardous energy control procedures, physical lockout/tagout isolations, and safety interlocks during equipment servicing.
2. **Category**: Personnel Safety Regulation.
3. **Does it define telemetry freshness?** **NO.** It defines safety isolation rules, not data freshness age or telemetry timeout limits.
4. **Does it apply to generator survivability?** Yes (hard interlock prohibiting dispatch).
5. **Does it apply to polar microgrids?** Yes (occupational safety law).
6. **Does it justify a POLARIS safety-credit rule?** **NO for Telemetry Freshness. YES for LOTO Interlock Governance.**
7. **Narrower legitimate claim**: OSHA LOTO establishes LOTO/Interlock Governance, requiring zero generator credit when maintenance lockout switches report an out-of-service state.

---

### 1.6 Caterpillar C9/C13 & Cummins OEM Specifications
1. **What does the source actually specify?** Manufacturer engine performance curves, Brake Specific Fuel Consumption (BSFC), ambient air intake thermal derating, and oil pressure trip limits.
2. **Category**: Manufacturer Technical Datasheet.
3. **Does it define telemetry freshness?** **NO.** OEM datasheets specify engine capabilities under clean laboratory conditions, NOT telemetry freshness thresholds.
4. **Does it apply to generator survivability?** Yes (defines fuel consumption and capacity limits).
5. **Does it apply to polar microgrids?** Partial (generic engine specs require polar installation derating).
6. **Does it justify a POLARIS safety-credit rule?** **NO (Justifies capacity bounds, not freshness limits).**
7. **Narrower legitimate claim**: OEM engine specs provide baseline fuel consumption curves and thermal derating functions for Class 1 evidence modeling.

---

### 1.7 Hydrostatic Fuel Sensor & Coriolis Flowmeter Datasheets
1. **What does the source actually specify?** Transducer measurement accuracy ($\pm 0.1\%$), sampling frequency ($10	ext{ s}$ level, $10–60	ext{ s}$ flow), and operating temperature ranges.
2. **Category**: Hardware Sensor Datasheet.
3. **Does it define telemetry freshness?** **NO.** Sensor sample rates specify transducer update frequency, NOT how long POLARIS can safely credit a fuel reading during a comms drop.
4. **Does it apply to generator survivability?** Indirectly (defines sensor noise and sample intervals).
5. **Does it apply to polar microgrids?** Partial (sensor datasheets must be validated for low-temp diesel viscosity and tank sloshing).
6. **Does it justify a POLARIS safety-credit rule?** **NO.**
7. **Narrower legitimate claim**: Sensor datasheets provide hardware sample rates and baseline noise specs for Class 1/2 sensor modeling.
