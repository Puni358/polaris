# POLARIS G1.3-E — CANDIDATE EXPERIMENTAL DATASET SPECIFICATIONS

## Executive Summary

This document specifies the candidate dataset parameters, ground-truth reference structures, instrumentation choices, and metadata targets for designing future physical telemetry freshness experiments across the 8 canonical generator classes.

In strict compliance with POLARIS governance:
- **Candidate Research Parameters**: Quantitative parameters (logging frequencies, timestamp precision targets, sample counts, observation durations) are explicitly labeled as **Candidate Experimental Design Parameters** and do NOT constitute established minimums or safety requirements.
- **Firewall Freshness Rules**: Sampling frequencies and timestamp precision targets define logger parameters for experimental research; they must **NEVER** be converted into POLARIS telemetry freshness thresholds ($T_{\text{freshness}}$).
- **Synthetic Assumptions**: Synthetic operating parameters (e.g. $100\text{ kW}$ genset capacity, $25\text{ L/h}$ fuel burn rate) are explicitly tagged `SYNTHETIC_ASSUMPTION` and are not Nuolja station facts.
- **Unverified External References**: External specifications (Caterpillar OEM curves, SAE J1939 protocols, OSHA LOTO regulations) are cited as candidate research models (`EXPERIMENT_DESIGN_PARAMETER`) because primary underlying source files are absent from the workspace repository.

## 1. CANDIDATE EXPERIMENTAL DATASET SPECIFICATIONS BY CANONICAL CLASS

### Class 1.1: Generator Operating State ($u(t) \in \{0, 1\}$)
- **Candidate Target Variables**: 
  - Shaft rotation speed (RPM) via magnetic pickup.
  - Generator main circuit breaker 52a (normally open) and 52b (normally closed) auxiliary contact state bits.
  - SCADA telemetry timestamp $t_{\text{sample}}$ and wall-clock arrival timestamp $t_{\text{receive}}$.
- **Candidate Timestamp Precision (Experiment Design Parameter)**: UTC UNIX epoch with proposed $\sim 10\text{ ms}$ timestamp accuracy for trip logging.
- **Synthetic Test Scenario (Synthetic Assumption)**: Uncommanded mechanical engine trip under full load ($100\text{ kW}$ synthetic scenario), overspeed electrical trip, emergency stop button press, breaker racked-out transition.
- **Candidate Ground-Truth Reference (Experiment Design Parameter)**: High-speed digital event logger wired directly to 52a/52b auxiliary contacts ($\sim 1\text{ ms}$ proposed sampling rate).
- **Candidate Metadata Targets**: SCADA gateway polling interval, network packet transmission protocol (Modbus TCP/Ethernet), switchgear contact debounce filter setting.
- **Candidate Sample Size Target (Experiment Design Parameter)**: Proposed target of $\sim 50$ independent trip/transition events recorded across varying generator operating loads.

### Class 1.2: Generator Active Power ($P_{\text{gen}}(t)$)
- **Candidate Target Variables**:
  - 3-phase AC line voltage ($V_{ab}, V_{bc}, V_{ca}$) and line current ($I_a, I_b, I_c$).
  - Instantaneous active power $P_{\text{true}}(t)$ [kW].
  - SCADA transmitted active power $P_{\text{observed}}(t - A)$ [kW].
- **Candidate Timestamp Precision (Experiment Design Parameter)**: UTC UNIX epoch with proposed $\sim 100\text{ ms}$ logging precision.
- **Synthetic Step-Load Scenario (Synthetic Assumption)**: Proposed step-load acceptance ($0 \to 100\text{ kW}$ synthetic scenario), step-load shedding ($100 \to 0\text{ kW}$), synthetic turbocharger efficiency loss power drop ($30\text{ kW}$ drop over $60\text{ s}$).
- **Candidate Ground-Truth Reference (Experiment Design Parameter)**: Class 0.2S revenue-grade power analyzer recording 3-phase AC terminals with candidate logging frequency of $1\text{ Hz}$.
- **Candidate Metadata Targets**: CT/PT transformer ratios, power analyzer integration window, SCADA deadband settings.
- **Candidate Observation Duration (Experiment Design Parameter)**: Proposed test duration of $24\text{ hours}$ continuous operation including a candidate target of $\ge 10$ major step-load transitions.

### Class 1.3: Generator Available Power / Capacity ($P_{\text{cap}}(t)$)
- **Candidate Target Variables**:
  - Engine intake manifold air temperature $T_{\text{intake}}$ [°C] and manifold absolute pressure $P_{\text{intake}}$ [kPa].
  - Differential pressure across air intake filter $\Delta P_{\text{filter}}$ [kPa].
  - Barometric pressure $P_{\text{amb}}$ and ambient temperature $T_{\text{ambient}}$ [°C].
  - Engine ECU derating flag and maximum allowable fuel rack limit.
- **Candidate Timestamp Resolution (Experiment Design Parameter)**: UTC UNIX epoch with proposed $\sim 1.0\text{ s}$ logging resolution.
- **Synthetic Polar Ambient Scenario (Synthetic Assumption)**: Polar blowing snow clogging air filter scenario, proposed ambient temperature drop ($0^\circ\text{C} \to -40^\circ\text{C}$ over $6\text{ h}$).
- **Candidate Ground-Truth Reference**: Direct ECU internal memory log of derating multipliers + intake vacuum sensor.
- **Candidate OEM Reference Model (Experiment Design Parameter — Primary OEM spec file absent from workspace)**: Caterpillar C9/C13 OEM derating curve coefficients (candidate reference model; primary OEM file unverified in workspace).
- **Candidate Observation Duration (Experiment Design Parameter)**: Proposed multi-day polar storm event observation duration.

### Class 1.4: Fuel Tank Level ($L_{\text{fuel}}(t)$)
- **Candidate Target Variables**:
  - Hydrostatic day-tank fuel level pressure [kPa] and calculated fuel volume $L_{\text{fuel}}$ [Liters or %].
  - Fuel temperature in day-tank $T_{\text{fuel\_tank}}$ [°C].
  - Fuel transfer pump ON/OFF state bit.
- **Candidate Timestamp Resolution (Experiment Design Parameter)**: UTC UNIX epoch with proposed $\sim 1.0\text{ s}$ resolution.
- **Synthetic Operating Scenarios (Synthetic Assumption)**: Synthetic generator fuel consumption ($25\text{ L/h}$ synthetic assumption `SYN_ASSUMP_02`), day-tank fuel line leak scenario ($5\text{\%/min}$ synthetic assumption `SYN_ASSUMP_05`), transfer pump failure starvation.
- **Candidate Ground-Truth Reference**: Calibrated fuel tank mass scale or dual redundant level sensors with mechanical stilling well.
- **Candidate Instrumentation Parameters (Experiment Design Parameter)**: Tank geometry dimensions, fuel density at sub-zero temperatures, candidate transmitter A/D resolution choice (e.g. $12\text{-bit}$).
- **Candidate Observation Duration (Experiment Design Parameter)**: Proposed test duration of $72\text{ hours}$ continuous day-tank operations.

### Class 1.5: Fuel Flow Rate ($\dot{m}_{\text{fuel}}(t)$)
- **Candidate Target Variables**:
  - Supply fuel line mass flow rate $\dot{m}_{\text{supply}}$ [kg/h] and fuel temperature $T_{\text{supply}}$ [°C].
  - Return fuel line mass flow rate $\dot{m}_{\text{return}}$ [kg/h] and fuel temperature $T_{\text{return}}$ [°C].
  - Calculated net fuel consumption rate $\dot{m}_{\text{net}} = \dot{m}_{\text{supply}} - \dot{m}_{\text{return}}$ [kg/h].
- **Candidate Timestamp Resolution (Experiment Design Parameter)**: UTC UNIX epoch with proposed $\sim 1.0\text{ s}$ resolution.
- **Synthetic Test Scenarios (Synthetic Assumption)**: Cold fuel gelling increasing return line restriction, fuel injector fouling changing BSFC.
- **Candidate Ground-Truth Reference (Experiment Design Parameter)**: Dual Coriolis mass flowmeters installed on supply and return fuel lines with candidate logging frequency of $1\text{ Hz}$.
- **Candidate Metadata Targets**: Arctic diesel fuel blend density/viscosity temperature correction curves, flowmeter zero-point calibration certificates.
- **Candidate Observation Duration (Experiment Design Parameter)**: Proposed observation duration of $12\text{ hours}$ generator operation.

### Class 1.6: Startup Readiness Telemetry (OFF Generator)
- **Candidate Target Variables**:
  - Engine block coolant temperature $T_{\text{block}}$ [°C] at multiple physical block locations.
  - Starter battery DC voltage $V_{\text{start}}$ [V] and cranking current $I_{\text{crank}}$ [A].
  - Engine block heater AC power supply voltage $V_{\text{heater}}$ and current $I_{\text{heater}}$.
  - Auto-start permissive bit and fuel solenoid permissive bit.
- **Candidate Logging Resolution Choices (Experiment Design Parameter)**: Proposed $\sim 10\text{ s}$ logging resolution during thermal decay; proposed $\sim 10\text{ ms}$ during engine cranking.
- **Synthetic Sub-Zero Test Conditions (Synthetic Assumption)**: Block heater power failure at sub-zero ambient ($T_{\text{ambient}} < -40^\circ\text{C}$ synthetic scenario), synthetic block thermal loss rate ($2.0^\circ\text{C/h}$ synthetic assumption `SYN_ASSUMP_03`).
- **Candidate Ground-Truth Reference**: Multi-point thermocouple logger installed on engine block + battery impedance analyzer.
- **Candidate Observation Duration (Experiment Design Parameter)**: Proposed test duration of $48\text{ hours}$ thermal decay recording following block heater power interruption.

### Class 1.7: Generator Health / Fault Status
- **Candidate Target Variables**:
  - Diagnostic trouble codes, Suspect Parameter Numbers (SPNs), Failure Mode Identifiers (FMIs).
  - Lube oil pressure [kPa], coolant temperature [°C], engine speed [RPM].
  - Hardware low oil pressure shutdown switch bit and overspeed shutdown contact bit.
- **Candidate Protocol Specification (Experiment Design Parameter — Primary SAE standard document absent from workspace)**: SAE J1939 CAN-bus protocol message structure reference (candidate protocol model; primary SAE document unverified in workspace).
- **Candidate Frame Capture Resolution (Experiment Design Parameter)**: Proposed $\sim 10\text{ ms}$ CAN sniffer capture resolution.
- **Candidate Fault Sample Target (Experiment Design Parameter)**: Candidate target of $\ge 20$ forced ECU fault latching events.
- **Candidate Ground-Truth Reference**: Vector / PEAK CAN-bus sniffer recording raw J1939 frames directly at ECU connector.

### Class 1.8: Maintenance / Lockout State
- **Candidate Target Variables**:
  - Hardwired Lockout/Tagout (LOTO) key switch auxiliary contacts (LOTO_OPEN / LOTO_LOCKED).
  - Generator main breaker manual trip handle mechanism position contact.
  - SCADA reported generator maintenance state bit.
- **Candidate Safety Governance Specification (Experiment Design Parameter — Primary OSHA text document absent from workspace)**: OSHA 29 CFR 1910.147 LOTO safety interlock governance reference (candidate safety governance model; primary OSHA regulation text unverified in workspace).
- **Candidate Input Sampling Resolution (Experiment Design Parameter)**: Proposed $\sim 1\text{ ms}$ logic analyzer digital input sampling resolution.
- **Open Hardware Parameter (Open Parameter)**: Switchgear auxiliary contact bounce duration (candidate target $< 5\text{ ms}$; requires empirical measurement on Nuolja switchgear).
- **Candidate Actuation Target Count (Experiment Design Parameter)**: Candidate target of $\ge 30$ manual LOTO key switch actuations.
