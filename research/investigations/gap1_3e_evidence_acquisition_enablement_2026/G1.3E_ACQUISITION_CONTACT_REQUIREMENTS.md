## 1. DATA REQUEST PACKAGE 1: POLAR STATION SCADA DATA (EVD-01)

### 1.1 Target Organization / Resource Type
- **Target Institutions**: Australian Antarctic Division (AAD) / British Antarctic Survey (BAS) / National Polar Research Institutes.
- **Target Resource**: Remote Antarctic station diesel generator microgrid SCADA system logs (Mawson / Halley VI Station).

### 1.2 Information Requested
- High-resolution time-series SCADA logs capturing generator operational state transitions, active power generation, and day-tank fuel level dynamics.

### 1.3 Exact Variables Required
1. Generator main circuit breaker status (52a/52b aux contacts or digital status bit $u \in \{0, 1\}$).
2. 3-phase AC active power output $P_{\text{gen}}(t)$ [kW].
3. Day-tank fuel volume or level percentage $L_{\text{fuel}}(t)$ [% or Liters].
4. Ambient outdoor temperature $T_{\text{ambient}}$ [°C] and station wind speed [m/s].

### 1.4 Ground-Truth & Metadata Requirements
- **Ground Truth**: SCADA master server event log timestamps with UTC UNIX epoch synchronization ($\le 1.0\text{ s}$ timestamp precision).
- **Metadata**: Generator engine model (Caterpillar/Perkins), nameplate kW rating, day-tank capacity (Liters), SCADA polling rate.

### 1.5 Requested Time Span & Data Format
- **Time Span**: 12 consecutive months of operational SCADA logs (minimum 3 months polar winter).
- **Format**: Raw unaggregated CSV or HDF5 time-series log files.

### 1.6 Confidentiality & Privacy Considerations
- Operational microgrid data only; no personnel, security, or sensitive research data requested.

## 2. DATA REQUEST PACKAGE 2: OEM ENGINE THERMAL & DERATING DATA (EVD-03)

### 2.1 Target Organization / Resource Type
- **Target Institutions**: Caterpillar Power Systems / Industrial Engine OEM Technical Engineering Teams.
- **Target Resource**: Environmental thermal chamber test datasets for industrial diesel engines (Caterpillar C9/C13 series).

### 2.2 Information Requested
- Multi-channel thermal thermocouple and intake pressure logs during sub-zero engine cold-soak, block heater failure, and intake filter restriction derating trials.

### 2.3 Exact Variables Required
1. Engine block coolant temperature $T_{\text{block}}$ [°C] at multiple block positions.
2. Ambient thermal chamber temperature $T_{\text{chamber}}$ [°C] ($+40^\circ\text{C}$ to $-40^\circ\text{C}$).
3. Engine starter battery DC voltage $V_{\text{start}}$ [V] and cranking current $I_{\text{crank}}$ [A].
4. Intake manifold air temperature $T_{\text{intake}}$ [°C] and manifold pressure $P_{\text{intake}}$ [kPa].
5. Engine ECU derating multiplier and active fuel rack limits.

### 2.4 Ground-Truth & Metadata Requirements
- **Ground Truth**: Engine test bench multi-channel thermocouple logger + ECU internal RAM trace.
- **Metadata**: Engine block thermal mass, coolant fluid heat capacity, enclosure insulation R-value, battery CCA rating.

### 2.5 Requested Time Span & Data Format
- **Time Span**: Complete thermal chamber test run sequences (48-hour cold soak + 12-hour derating run).
- **Format**: Unaggregated OEM test bench CSV / MAT files.

### 2.6 Confidentiality & Privacy Considerations
- Proprietary OEM derating parameters; request subject to formal non-disclosure agreement (NDA).

## 3. DATA REQUEST PACKAGE 3: SWITCHGEAR LAB HIL DATA (EVD-05)

### 3.1 Target Organization / Resource Type
- **Target Institutions**: University Power Systems Laboratories / National Laboratory High-Voltage Switchgear Facilities.
- **Target Resource**: 480V Industrial switchgear auxiliary contact digital logic analyzer test bench.

### 3.2 Information Requested
- High-speed digital input capture logs recording auxiliary contact state transitions and contact bounce dynamics during manual Lockout/Tagout (LOTO) key switch actuation and breaker racking.

### 3.3 Exact Variables Required
1. LOTO key switch auxiliary contact state bit (LOTO_OPEN / LOTO_LOCKED).
2. Breaker manual trip handle mechanism position bit.
3. Switch auxiliary contact current loop voltage $V_{\text{aux}}$ [V].
4. Contact bounce pulse train timestamps [ms].

### 3.4 Ground-Truth & Metadata Requirements
- **Ground Truth**: Digital logic analyzer direct channel sampling at $1\text{ ms}$ or higher resolution.
- **Metadata**: Switchgear model, auxiliary contact block manufacturer, contact debounce filter settings.

### 3.5 Requested Time Span & Data Format
- **Time Span**: Recording of at least 30 manual LOTO switch actuations and breaker racking operations.
- **Format**: Raw digital logic analyzer export (CSV or VCD format).

### 3.6 Confidentiality & Privacy Considerations
- Non-proprietary laboratory switchgear test bench data; no confidentiality restrictions anticipated.
