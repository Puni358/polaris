# POLARIS — G1.3-E EMPIRICAL GAP ANALYSIS & RESEARCH PROGRAM

## Executive Summary

This document presents a rigorous gap analysis across the 8 canonical generator resource/measurement classes and outlines the empirical research and testing program required to advance POLARIS telemetry freshness from **Evidence Boundary C** ("Evidence Insufficient — Additional Empirical Research Required") toward validated governance rules.

---

## 1. NINE CORE GAP ANALYSIS QUESTIONS

### Question 1: Which of the 8 canonical classes have directly validated telemetry freshness evidence?
**Answer: ZERO (0 of 8).**
No canonical resource/measurement class currently possesses directly validated empirical evidence establishing a numerical telemetry freshness validity threshold ($T_{\text{freshness}}$). All 8 classes remain at Evidence Boundary C.

### Question 2: Which of the 8 canonical classes have only indirect engineering evidence?
**Answer: SIX (6 of 8).**
The following 6 classes rely on indirect engineering evidence (standards, OEM specifications, and physical dynamics models):
- Class 1.1: Generator Operating State ($u(t)$) — IEEE 1547.4 / IEC 61850 breaker timing.
- Class 1.2: Generator Active Power ($P_{\text{gen}}(t)$) — IEEE 1547 power metering dynamics.
- Class 1.3: Generator Available Capacity ($P_{\text{cap}}(t)$) — Caterpillar OEM derating curves.
- Class 1.4: Fuel Tank Level ($L_{\text{fuel}}(t)$) — Hydrostatic sensor datasheets & volume integration.
- Class 1.5: Fuel Flow Rate ($\dot{m}_{\text{fuel}}(t)$) — Coriolis flowmeter specifications.
- Class 1.6: Startup Readiness Telemetry ($V_{\text{start}}$, $T_{\text{block}}$, solenoids) — NFPA 110 & cold-start specs.

### Question 3: Which of the 8 canonical classes have no usable evidence?
**Answer: ONE (1 of 8) for raw data; ALL EIGHT (8 of 8) for numerical freshness thresholds.**
- Class 1.8 (Maintenance / Lockout State) relies on SRC-05 (OSHA LOTO 1910.147), which is directly verified for LOTO/interlock governance, but provides **zero** evidence for a numerical telemetry freshness age limit.
- Class 1.7 (Health / Fault Status) cites SRC-08 (Antarctic SCADA logs), which is `SOURCE_UNVERIFIED` because raw/processed field logs are absent from the workspace.
- Across all 8 classes, zero usable empirical data exists in the repository to justify a numerical cutoff (e.g. 30s, 300s, 900s).

### Question 4: Which timing claims in prior research are merely sampling or update intervals?
**Answer: ALL NUMERICAL TIMING CLAIMS IN PRIOR RESEARCH ARE OPERATIONAL/INSTRUMENT INTERVALS, NOT FRESHNESS TIMEOUTS.**
- **30–100 ms**: Physical mechanical disconnect trip speed of AC circuit breakers (IEEE 1547.4). It is the duration of mechanical opening, NOT a SCADA telemetry validity window.
- **1–5 s**: Standard SCADA serial/network polling period over Modbus/DNP3. It is transmission frequency, NOT a safety-credit validity limit.
- **100 ms / 1000 ms**: SAE J1939 ECU CAN-bus message broadcast rates. They are periodic frame transmission intervals, NOT POLARIS freshness validity bounds.
- **10 s**: NFPA 110 Type 10 standby generator starting requirement. It is an emergency startup target time, NOT a telemetry freshness timeout.
- **10 s / 10–60 s**: Hydrostatic level sensor sample rates and Coriolis mass flowmeter integration windows. They represent measurement integration periods, NOT safety-credit validity cutoffs.

### Question 5: Which evidence is actually transferable to Nuolja station?
**Answer: ONLY GOVERNANCE PRINCIPLES (SRC-05 OSHA LOTO); NO NUMERICAL FRESHNESS THRESHOLDS ARE CURRENTLY TRANSFERABLE.**
- **Transferable**: SRC-05 (OSHA LOTO 1910.147) governance principles. Hardwired LOTO safety interlocks apply universally to energy systems, including Nuolja microgrid.
- **Not Transferable**: Numerical timing from generic standards (IEEE, IEC, SAE, NFPA) or OEM specs (Caterpillar) cannot be transferred as Nuolja-specific freshness requirements without site-specific network, thermal, and physical measurements. Antarctic station claims (SRC-08) cannot be transferred because raw data is missing (`TRANSFER_TO_NUOLJA_JUSTIFIED = NO`).

### Question 6: What empirical experiments are required to establish defensible freshness requirements?
**Answer: EIGHT TARGETED EMPIRICAL EXPERIMENTS (ONE PER CLASS).**
(Detailed experimental designs are provided in Section 2 below).

### Question 7: What measurements would those experiments need?
**Answer:**
- High-speed SCADA link latency, packet loss, and frame arrival timestamps.
- Generator electrical output (CT/PT 1 kHz logging during step-load and trip events).
- Engine block temperature decay rates ($T_{\text{block}}$) under sub-zero enclosure airflow loss.
- Fuel day-tank level transducer response during engine vibration and static settling.
- Low-temperature fuel viscosity and mass flowmeter differential supply/return readings.
- ECU CAN-bus message latency and gateway buffer delays under simulated fault injection.

### Question 8: What failure/decision outcomes should be evaluated?
**Answer:**
- Critical-load energy deficit ($\Delta E_{\text{surv}} < 0$) over 6-hour evaluation window.
- Unannounced generator trip under dispatch while SCADA reports online state.
- Standby generator cranking failure upon start command due to un-detected block heater loss.
- Engine thermal trip under full load due to un-detected air intake restriction.
- Day-tank fuel depletion prior to modeled horizon end.
- LOTO safety interlock breach during maintenance operations.

### Question 9: What evidence would be sufficient to move a class from Evidence Boundary C toward a governance review?
**Answer:**
To move a resource class from Evidence Boundary C to Evidence Boundary B or A, the project requires:
1. **Direct Empirical Trial Data**: Logged time-series data from Nuolja station hardware or a validated Hardware-in-the-Loop (HIL) testbed simulating polar conditions.
2. **Empirical Error Quantification**: Demonstrated mathematical relationship between telemetry staleness age ($\Delta t$) and decision error ($\epsilon(P), \epsilon(E)$).
3. **Peer-Reviewed / OEM Site Validation**: Formally recorded OEM site test or empirical validation proving that a specific threshold ($T_{\text{freshness}}$) guarantees decision safety within acceptable error bounds under all operational regimes.

## 2. PROPOSED EMPIRICAL RESEARCH & TESTING PROGRAM

Where evidence is currently insufficient, the following minimum empirical experiments are proposed:

### Experiment 1: HIL Generator Trip & SCADA Latency Test (Class 1.1)
- **Target Class**: 1.1 Generator Operating State ($u(t)$).
- **Telemetry Variable**: Breaker auxiliary switch contact ($52a/52b$) and engine RPM.
- **Controlled Delay Injection**: Inject 0 s to 300 s artificial SCADA communication delays during simulated electrical trips.
- **Operational Condition**: Full load dispatch ($P_{\text{gen}} = 50\text{ kW}$).
- **Observable Outcome**: Time delta between physical breaker trip and POLARIS state update; calculated false credit energy $\Delta E$.
- **Acceptance Metric**: State error detection within $\le \Delta t_{\text{max}}$ where false energy credit $\le 0.1\text{ kWh}$.
- **Required Repetitions**: 50 trip injections across varying network traffic loads.

### Experiment 2: Polar Step-Load & Derating Transient Response (Class 1.2)
- **Target Class**: 1.2 Generator Active Power ($P_{\text{gen}}(t)$).
- **Telemetry Variable**: Active AC power ($kW$).
- **Controlled Delay Injection**: Delay power telemetry updates by 5 s, 15 s, 30 s, 60 s, 300 s during 50% step-load drops.
- **Operational Condition**: Rapid load change or sudden thermal derate.
- **Observable Outcome**: Accumulated energy estimation error $\int |P_{\text{actual}}(t) - P_{\text{reported}}(t-\Delta t)| dt$.
- **Acceptance Metric**: Energy error bounded within $\le 1.0\%$ of 6-hour critical load demand ($0.696\text{ kWh}$).
- **Required Repetitions**: 30 step-load cycles.

### Experiment 3: Intake Airflow Restriction & Thermal Decay Test (Class 1.3)
- **Target Class**: 1.3 Generator Available Power / Capacity ($P_{\text{cap}}(t)$).
- **Telemetry Variable**: Intake air temperature, manifold pressure, ambient temperature.
- **Controlled Delay Injection**: Freeze ambient/intake telemetry for 10 min to 2 hours while progressively restricting intake airflow (simulating snow clogging).
- **Operational Condition**: Cold-ambient full-load run.
- **Observable Outcome**: Time to engine thermal derate vs. POLARIS capacity model error.
- **Acceptance Metric**: Capacity model overestimation bounded within 2.0 kW over 6-hour horizon.
- **Required Repetitions**: 10 thermal chamber run cycles.

### Experiment 4: Day-Tank Slosh & Low-Temp Level Response Trial (Class 1.4)
- **Target Class**: 1.4 Fuel Tank Level ($L_{\text{fuel}}(t)$).
- **Telemetry Variable**: Hydrostatic fuel level sensor voltage / volume reading.
- **Controlled Delay Injection**: Inject telemetry delays (1 min to 30 min) during simulated fuel leak ($5\%/\text{min}$).
- **Operational Condition**: Engine running with building vibration + low temperature fuel.
- **Observable Outcome**: Fuel sufficiency credit error vs. physical fuel remaining.
- **Acceptance Metric**: Fuel level error detection before day-tank reaches reserve threshold ($15\%$).
- **Required Repetitions**: 20 leak simulation runs.

### Experiment 5: Polar Fuel Viscosity & Flowmeter Calibration Trial (Class 1.5)
- **Target Class**: 1.5 Fuel Flow Rate ($\dot{m}_{\text{fuel}}(t)$).
- **Telemetry Variable**: Supply and return mass flowmeter rates.
- **Controlled Delay Injection**: Freeze flow rate telemetry for 5 min to 1 hour while fuel temperature drops from $+15^\circ\text{C}$ to $-30^\circ\text{C}$.
- **Operational Condition**: Cold fuel circulation.
- **Observable Outcome**: Mass balance error ($\dot{m}_{\text{supply}} - \dot{m}_{\text{return}}$) vs. actual BSFC.
- **Acceptance Metric**: BSFC calculation error $< 3\%$.
- **Required Repetitions**: 15 thermal loop cycles.

### Experiment 6: Sub-Zero Block Heater Failure Thermal Decay Trial (Class 1.6)
- **Target Class**: 1.6 Startup Readiness Telemetry (OFF Generator).
- **Telemetry Variable**: Engine block coolant temperature ($T_{\text{block}}$).
- **Controlled Delay Injection**: Disconnect block heater power at $-40^\circ\text{C}$ ambient; delay $T_{\text{block}}$ telemetry updates by 15 min, 1 h, 3 h, 6 h.
- **Operational Condition**: Standby OFF generator ($u=0$).
- **Observable Outcome**: Engine cranking success / start time vs. $T_{\text{block}}$ telemetry age.
- **Acceptance Metric**: Detection of $T_{\text{block}} < 20^\circ\text{C}$ threshold prior to start dispatch command.
- **Required Repetitions**: 10 cold-soak decay trials.

### Experiment 7: ECU CAN-Bus Fault Injection & Gateway Latency Trial (Class 1.7)
- **Target Class**: 1.7 Generator Health / Fault Status.
- **Telemetry Variable**: ECU Diagnostic Trouble Codes (DTCs), oil pressure alarm bit.
- **Controlled Delay Injection**: Inject ECU active faults while delaying SCADA gateway polling from 100 ms to 60 s.
- **Operational Condition**: Engine start command under active latent fault.
- **Observable Outcome**: Time delta between fault occurrence in ECU and SCADA latching; start attempt outcome.
- **Acceptance Metric**: Active fault detection prior to start command execution.
- **Required Repetitions**: 50 CAN fault injections.

### Experiment 8: Auxiliary Contact Bounce & LOTO Interlock Test (Class 1.8)
- **Target Class**: 1.8 Maintenance / Lockout State.
- **Telemetry Variable**: 52a/52b aux switch contact state and LOTO key selector state.
- **Controlled Delay Injection**: Mechanically toggle LOTO switch; record contact bounce and SCADA propagation time.
- **Operational Condition**: Maintenance lockout transition.
- **Observable Outcome**: Verification of immediate hardwired interlock trip before SCADA polling update.
- **Acceptance Metric**: Deterministic interlock override in $< 10\text{ ms}$ via hardwiring (independent of SCADA polling rate).
- **Required Repetitions**: 100 mechanical switch operations.
