# POLARIS — G1.3-E EMPIRICAL SOURCE REGISTER

## Executive Summary

This register records the empirical source evaluation for all eight candidate evidence sources (SRC-01 through SRC-08) evaluated during the **G1.3-E Empirical Evidence Acquisition** phase.

Each source has been audited against the authoritative source verification standards:
- `DIRECTLY_VERIFIED`: Original document locally available in workspace, passage inspected, exact claim verified.
- `REFERENCE_VERIFIED_BUT_NUMERICAL_SUPPORT_UNVERIFIED`: Reference identity verified from standard/OEM literature, but underlying source PDF/passage is not stored in workspace. Numerical claims remain unverified against primary source text.
- `SOURCE_UNVERIFIED`: Source document unavailable in workspace and reference identity unverified.
- `MISREPRESENTED_SOURCE`: Source materially misstates or contradicts cited claim.
