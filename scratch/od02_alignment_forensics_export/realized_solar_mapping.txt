3. CROSS-SYSTEM RECONCILIATION & INSIGHTS
--------------------------------------------------------------------------------
1. Why Step 0 queries `t0 + 1h`:
   In discrete-time physical simulation (`DigitalTwinSimulator.step()`), an agent
   executes action $u_0$ across $[t_0, t_0+1\text{h}]$, arriving at state $S_1$ at $t_0+1\text{h}$.
   The realized loader pairs transition step 0 with the environmental reading stamped
   at the end of that transition interval (`t0 + 1h`).
2. Impact on Solar Forecast Alignment:
   - Raw N6 output index 0 was stamped $t_0 + 0\text{h}$ (`2024-06-07T00:00:00Z`).
   - Raw N6 output index 1 was stamped $t_0 + 1\text{h}$ (`2024-06-07T01:00:00Z`).
   - Because `realized_loader.py` evaluates step 0 against `01:00:00Z`, the author of
     `_align_n6_bundle_od02` mapped N6 index 1 (`01:00:00Z`) to dispatch step 0 so that
     the forecast label (`01:00:00Z`) matches the realized observation query label (`01:00:00Z`).
   - Symmetrically, step 23 evaluates against `t0 + 24h` (`2024-06-08T00:00:00Z`), for which
     raw N6 (having only 24 points $t_0 \dots t_0+23\text{h}$) had no corresponding output.
