# FIVE TIER LOAD ARCHITECTURE

## CONCEPTUAL FIVE-TIER LOAD DECOMPOSITION

- **Tiers**:
  - Tier 1: Protected Critical (Human life, freeze protection, emergency comms)
  - Tier 2: Essential Operational
  - Tier 3: Standard Operational
  - Tier 4: Deferrable / Flexible
  - Tier 5: Non-essential / Discretionary
- **Mathematical Abstraction**:
  $$\sum_{i=1}^{5} P_{\text{demand,tier\_i}}(t) = P_{\text{demand,total}}(t)$$
