# LIMITATIONS

## Isolated Validation Scope & Engineering Boundaries

This document defines the strict limitations of this isolated validation package.

---

## Prohibited Overclaims

This validation demonstrates technical facts about `highspy-1.15.1` on synthetic toy MILP problems. It MUST NOT be used to claim:
1. That Option B is superior, safer, faster, or better than Option A.
2. That Option B is ready for live operational deployment without team decision and full system integration testing.
3. That performance timing on a 2-variable toy MILP predicts 24-step production MPC performance.
4. That Option B has been selected by automated tools.
