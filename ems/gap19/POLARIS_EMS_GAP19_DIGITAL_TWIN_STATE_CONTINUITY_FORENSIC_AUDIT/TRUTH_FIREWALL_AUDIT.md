## 1. Information Boundary Inspection

Tracing information passed into `GAP19HighsNativeOptimizer.optimize(...)`:

```python
plan = self.optimizer.optimize(bundle, current_state, self.configs)
```

1. **`bundle` (ForecastBundle)**: Generated by `LocalBaselineForecastEngine.predict(current_state, runtime_context)` using only observation-time data $t_n$ and baseline forecasting logic.
2. **`current_state` (StationState)**: Holds observed state at origin time $t_n$ ($E_n, \text{SOC}_n, \text{diesel\_running}_n, \text{diesel\_hours}_n, t_n$).
3. **Ground Truth (`next_actual`)**: Sourced via `data_provider.get_future_ground_truth(step_idx, horizon_hours=24)[0]` and supplied exclusively to `DigitalTwinSimulator.step(...)`.

## 2. Firewall Assessment

- **Digital Twin Truth Access**: `DigitalTwinSimulator` accesses ground truth `next_actual` to compute true physical physical environment transitions. This is legitimate simulator operation.
- **Controller Truth Access**: The controller (`ForecastEngine` and `EnergyOptimizer`) receives **ZERO** future actual demand, solar, or wind data from `next_actual`.
- **Private Simulator State**: Zero private internal simulator variables are leaked back into `StationState` or `ForecastBundle`.
