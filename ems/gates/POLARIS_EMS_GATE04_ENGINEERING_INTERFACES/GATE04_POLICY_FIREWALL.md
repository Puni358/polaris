## 2. EXPLICIT REGISTER OF PROHIBITED INVENTIONS

Developers, software mappers, and AI assistants MUST NOT invent any of the following parameters during engineering interface design:

1. **Numerical Thresholds**: No $SOC_{\text{recovery}}$, $Fuel_{\text{recovery}}$, or $N_{\text{stable}}$ cycle thresholds.
2. **SOC / Fuel Quantities**: No arbitrary reserve percentages or fuel volume cutoffs.
3. **Load Percentages**: No arbitrary shedding percentages for flexible or interruptible loads.
4. **Authentication Mechanisms**: No OAuth2, SAML, JWT, API tokens, or LDAP classes.
5. **RBAC / MFA**: No user role permission scopes or multi-factor authentication workflows.
6. **Operator Timeout Values**: No notification timeouts, override expiration windows, or acknowledgement timers.
7. **Hardware Interfaces**: No physical PLC contactor schematics or RTU relay mappings.
8. **New Policy**: No new operational policies or emergency severity tiers.
