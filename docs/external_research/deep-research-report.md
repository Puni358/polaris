# Potential Novel Forecast Inputs for POLARIS

**1. SEVIRI Satellite Cloud Physical Properties (CPP)** – Pixel-level cloud optics from EUMETSAT’s NWC SAF.  SEVIRI geostationary imagery processed by NWCSAF produces **cloud phase, optical thickness (COT), effective particle radius, liquid/ice water path**, etc..  This gives *actual observed cloud optical depth and microphysics* overhead.  Stage 8.1 currently uses only *modeled* LWP/IWP and steering winds; it lacks direct cloud optical thickness and droplet size.  SEVIRI CPP is available near-real-time (≈15 min) and has full coverage of Nuolja (MSG covers Scandinavia).  Its archives extend through 2024.  Latency is low (operational nowcasts exist).  Causally this data exist before t0 and would have been available (SEVIRI images are continuous).  It is independent of MEPS (observational vs model).  POLARIS did **not** include SEVIRI cloud retrievals; Stage 8.9A (“cloud-state sources”) was closed without testing this.  The closest prior work is advective cloud forecasts using these properties.  **Failure modes:** retrieval errors (day/night variability, thin clouds), misclassified cloud phase, partial coverage in polar twilight.  **Implementation:** moderate difficulty – requires satellite processing and data ingestion pipeline.  **Evidence:** Studies show SEVIRI-derived COT/CTH significantly improve short-term solar forecasts.  **Feasibility audit:** likely warranted.  

*Novelty:* **A (genuinely new data)** – surface cloud optical thickness and microphysics from SEVIRI were not in any tested feature set and represent new observational information.  
*Causal:* Yes (SEVIRI imagery acquired before t0, operational).  *Coverage:* Global over Scandinavia at 3–5 km resolution, hourly or better.  *Physical relevance:* High (cloud optical depth directly modulates SWIN).  *Implementation:* Medium (requires ingesting SAFNWC data or reprocessing SEVIRI).  *Evidence confidence:* Strong (published use in solar forecasts, e.g. Wang et al.).  

**2. Geostationary Satellite Cloud-Nowcast (ML U-Net)** – Deep-learning total cloud cover predictions (e.g. FMI’s **CloudCast**).  CloudCast is a convolutional neural network trained on SEVIRI imagery that nowcasts *total cloud cover* up to ~5 h ahead.  It directly forecasts cloud distribution and evolution beyond simple advection (learning formation/dissipation).  Input is multi-spectral SEVIRI images; output is predicted cloud mask.  Stage 8.1 has no such data; this is a completely independent means of predicting cloud cover patterns.  Historical archives of SEVIRI allow retraining or playback for 2024.  Temporal res: 5–15 min imagery; CloudCast outputs hourly or finer forecasts.  Spatial: 4–5 km scale.  Coverage: MSG full disk, includes Scandinavia.  Latency: similar to satellite refresh (minutes).  Data acquired before t0 by design of nowcast, so causally available.  Independent: yes (not from MEPS).  No equivalent prior Polaris route was tested.  (Stage 8.9A “cloud-state sources” did not include an ML nowcast product.)  Relevant reference: CloudCast reduced cloud forecast error by ~24% vs NWP.  **Failure modes:** It is short-range (skill <3–4 h), blurs new cloud formation beyond that; may not capture high clouds well.  **Implementation:** High difficulty – needs substantial ML infrastructure and archived training data, but code is available.  **Evidence:** Recent work shows ML nowcasts significantly outperform NWP for short horizons.  **Audit:** Worth feasibility study.  

*Novelty:* **A (genuinely new)** – machine-learned satellite nowcasts were not in Polaris.  *Causal:* Yes (uses imagery before t0).  *Coverage:* Full-sky SEVIRI, 5 km, 5–15 min updates.  *Relevance:* High (direct cloud cover forecasting; wins over NWP up to 3 h).  *Implementation:* Challenging (ML model building, but operational success reported).  *Evidence:* Good (peer-reviewed arXiv and FMI reports).  

**3. Local Surface Observations (Nuolja AWS)** – In-situ station meteorology at the site.  The SITES Abisko/Nuolja station records *air temperature, relative humidity, precipitation* etc..  These provide *current boundary-layer conditions*: e.g. high RH or recent rain indicates clouds.  Stage 8.1 uses only past SW_IN, not these meteorological sensors.  Data are available in real-time and archived (2024 station data exists).  Temporal: sub-hourly (here ~hourly).  Spatial: point at Nuolja.  Latency: minimal.  Causality: yes (observed before t0).  Independent: yes (on-site instruments).  Not previously tested in Polaris (no mention of including AWS data).  Most relevant: basic persistence models might use cloud sensors, but Polaris has not.  **Failure:** Local T/RH partly reflect cloud cover but also local microclimate (e.g. valley inversions) – correlation to high-altitude clouds is indirect.  Fog/snow could mislead.  **Impl.:** Low (just ingest an open dataset).  **Evidence:** Many forecasting systems use local pressure/humidity to tweak irradiance forecasts (though not commonly reported in literature).  **Audit:** Possibly, due to simplicity.  

*Novelty:* **A/B (new sensor data)** – ground T/RH not used before in Polaris (likely new information).  *Causal:* Yes.  *Coverage:* Only Nuolja site.  *Relevance:* Moderate (indirect indicator of cloudiness).  *Implementation:* Easy (raw data available).  *Evidence:* Sparse; more domain knowledge than peer literature.  

**4. Atmospheric Stability / Convective Indices (CAPE, Lifted Index, PBLH)** – Measures of instability from meteorology.  E.g. **CAPE** quantifies the potential for convective cloud growth.  High CAPE means strong potential updrafts and cumulus cloud formation; low CAPE suggests stable, stratiform skies.  Nuolja is alpine – convective clouds (cumulus) can form on sunny days.  CAPE and related indices (e.g. Lifted Index, boundary-layer height) from forecasts or reanalysis would signal cloud *formation tendency*.  These are not explicitly in Stage 8.1 (which uses only winds and water content).  Data: can be computed from MEPS or ERA5 profiles up to t0 and fed as features.  Temporal: typically 3-hourly model output.  Spatial: single location (or small grid).  Latency: from final analysis (few hours).  Causality: yes (atmospheric state at t0).  Independent: partly (derived from model, but describing a different aspect).  Polaris has not tested CAPE/LFC as features.  Similar work: meteorological forecasts often use convective indices for precipitation, but rarely for irradiance.  **Failures:** CAPE can be nonzero without actual clouds (needs trigger), or clouds can form with low CAPE (e.g. stratus).  Also CAPE at midday may not represent whole next day.  **Impl.:** Low–medium (computational but straightforward).  **Evidence:** CAPE is a standard measure of convective cloud potential; its impact on irradiance is plausible but untested.  **Audit:** Worth brief check if CAPE correlates to SW error.  

*Novelty:* **B (new representation of forecast data)** – These indices come from already-modeled profiles, but Polaris hasn’t used them explicitly.  *Causal:* Yes (analyzed state).  *Coverage:* Global forecasts include CAPE anywhere.  *Relevance:* Medium (indirect indicator of cloud formation).  *Implementation:* Easy (just compute from model fields).  *Evidence:* Conceptual only.  

**5. Cloud Motion Vectors (Multi-layer)** – Direct cloud tracking from satellite.  Traditional **Atmospheric Motion Vectors (AMVs)** or modern ML trackers compute actual wind vectors by tracking cloud patterns in successive SEVIRI images.  Unlike 700 hPa mean wind, AMVs capture how *cloud layers* move (cirrus vs low cumulus).  EUMETSAT provides global AMVs (though often used in NWP).  A 3D approach (multi-layer CMV) was shown to improve short-term cloud forecasts.  Stage 8.1 uses only 700 hPa wind as proxy.  True observed cloud motion vectors (especially multi-layer) would be novel.  Data: CAMS or SAF products (or research datasets) give AMVs at ~15-min resolution.  Temporal/spatial: ~1h, few-km.  Causality: yes (derived from imagery up to t0).  Independent: yes.  Not explicitly tested in Polaris (8.9A closed, but unclear exactly what was tried).  **Failure:** AMVs can be noisy or mis-identified, especially under low contrast or small clouds.  **Impl.:** Medium (data ingestion and 3D layering needed).  **Evidence:** Kosmopoulos et al. (2024) found multi-layer CMVs plus satellite microphysics gave up to ~80 W/m² RMSE (12% error), indicating benefit.  **Audit:** Possibly, but given 8.9A results, may be redundant with 700 hPa wind.  

*Novelty:* **D (likely duplicate/uncertain)** – Polaris considered “independent cloud-motion” and closed it; multi-layer tracking is an extension, but fundamentally similar idea.  *Causal:* Yes (satellite images before t0).  *Coverage:* MSG full disk, 5–15 min.  *Relevance:* Medium (direct cloud displacement).  *Implementation:* Moderate.  *Evidence:* Good performance reported, but applicability beyond 4h is limited.

- **BEST next feasibility audit:** *Satellite Cloud Optical Thickness (CPP)*.  Its novelty is high and physically directly relevant; mature research suggests strong benefit.  
- **Second-best:** *Satellite Cloud-Nowcast (CloudCast/ML)* – very novel and directly targets cloud evolution, though implementation is harder.  
- **Strongest unresolved hypothesis:** *Cloud optical properties vs. evolution* – are thin high clouds (cirrus) or rapid cloud dissipation the main error drivers? CPP/ML address this.  
- **Most likely false lead:** *Cloud displacement error* – the 700 hPa wind model already addresses advection; extensive prior work suggests this is not the sole issue (8.1 champion still far from perfect).  The “wind steering” success may lull into over-emphasizing motion.  
- **Key discriminator information:** A detailed cloud cover evolution measure (e.g. ML nowcast vs. actual change) would discriminate whether error stems from timing/formation vs displacement.  For instance, short-range cloud cover forecasts vs actual would show if clouds are forming/dissipating unexpectedly (favoring ML nowcast) or simply mis-advected.

**Recommendation:** Based on current evidence, the **Satellite Cloud Physical Properties (CPP)** candidate merits a feasibility audit before any full experiment. It is genuinely new (A) and highly relevant, with strong supporting studies.
