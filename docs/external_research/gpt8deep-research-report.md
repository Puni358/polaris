# Top 5 breakthrough hypotheses

- **Hypothesis 1: Satellite-based cloud nowcasting (spatio-temporal CNN on cloud fields).** Clouds are the dominant source of day-to-day irradiance variability, so explicitly forecasting cloud cover and advection could greatly reduce error.  Geostationary satellite imagery can be converted to a *cloud index* (CI) that quantifies cloud attenuation of irradiance.  A modern approach (e.g. “HelioNet”) uses a convolutional neural net (U-Net) to take a sequence of past CI images and predict future CI maps.  This directly addresses the missing information: how clouds will move/appear over the station.  POLARIS did not previously use full satellite nowcasting, so this idea is fresh.  At forecast time *t₀*, satellite images (at least the most recent one) are available causally.  Such models are most useful at short horizons (minutes–a few hours); HelioNet saw ∼11–15% RMSE improvement in the first hour vs. standard motion-vector methods.  Implementation is **medium** difficulty (need image data pipeline and CNN training) and data risk is moderate (requires access to frequent satellite imagery covering the site).  Leakage risk is zero (only past images used).  A falsifying experiment is to train a CNN on archived satellite CI sequences to predict irradiance, and compare its MAE/nMAE to the current champion on the odd half of data – e.g. adding only this new feature to the same model.  If error does **not** drop by ≳10%, the hypothesis is weak.  

- **Hypothesis 2: Physics-based clear-sky baseline + ML residual.**  Solar irradiance has a strong deterministic component (solar geometry, atmospheric transmission) and a stochastic residual (cloud effects).  First compute a physical clear-sky GHI (using e.g. the McClear or Bird model given latitude, time, airmass, aerosol and water vapor) and then train an ML model to predict the residual (actual minus clear-sky).  This explicitly encodes known physics so the model only “learns” cloud and weather perturbations.  Such physics‐informed residual learning has shown major gains (e.g. Shikdar 2026 finds greatly improved reliability at a high-latitude site).  This tackles the missing information that cloud attenuation was not separately modeled by the champion.  POLARIS to date has not implemented a dedicated clear-sky physics prior or residual-correction model.  The inputs needed (sun position, clear-sky irradiance) are fully known at t₀ with no leakage.  This approach benefits all horizons (it always enforces the diurnal cycle baseline).  Expected improvement is large: other studies report far lower RMSE when using a clear-sky prior (one PV forecasting implementation saw an 85% RMSE reduction vs. persistence).  Difficulty is **low-to-moderate** (implementing a clear-sky model and hooking up ML).  Data-risk is low (all inputs deterministic); leakage risk is nil.  A falsifying test is to train two models – one on raw GHI (current approach) and one on clear-sky-index (CSI = GHI/clear-sky) plus clear-sky baseline – and see if the CSI model fails to outperform the raw model.  If adding the clear-sky decomposition does **not** substantially cut error, the hypothesis is weakened.  

- **Hypothesis 3: Regime-switching / mixture-of-experts models.** Solar irradiance behaves very differently under different “weather regimes” (clear sky, overcast, broken clouds, sunrise/sunset transitions, etc.).  Physically, these regimes have distinct error patterns and might benefit from specialized models.  A mixture-of-experts approach (or first classifying the regime from NWP/cloud cover then applying a matched model) can reduce bias in each regime.  This addresses errors from abrupt transitions (e.g. cloud-edge enhancements or morning ramps) that a one-size model must average over.  We have no evidence POLARIS tried explicit regime models (beyond generic ML).  At t₀ a regime label could be obtained from forecast cloudiness or solar elevation.  Benefits would appear especially around sunrise/sunset and rapid cloud changes.  Improvement potential is **moderate**: if one model cannot handle all regimes, a two- or three-model mix could yield several-percent gains.  Difficulty is **medium** (defining regimes and training multiple models).  Data-risk: low (uses existing inputs); leakage: none.  Falsification: cluster the training set by a simple proxy (e.g. initial cloud cover or net irradiance) and train separate models; if this hybrid yields no better error than a single model, regime-specific modeling is not effective.  

- **Hypothesis 4: Multi-task learning (predict GHI, DNI, DHI and clear-sky index together).**  GHI (global horizontal), DHI (diffuse horizontal) and DNI (direct normal) are physically related: GHI = DHI + DNI·cos(zenith).  A multi-output model sharing representations can exploit these relationships.  For example, clouds turn direct sunlight into diffuse.  By predicting all three components (or GHI plus clear-sky index) simultaneously, the model may learn a better internal cloud representation.  The champion appears to predict only GHI.  Data needed are standard (the extra targets can be computed via a clear-sky model or NWP if not measured).  This addresses missing structure (no current model enforces GHI= DHI+DNI·cosθ).  We expect modest gains (a few percent) from enforcing physical consistency.  Difficulty is **low** (just add extra output heads); data-risk is moderate (need reliable DHI/DNI proxies).  Leakage risk: none.  To test, train a neural net with two outputs (e.g. GHI and DHI) and check if GHI error drops; if it does not, then multi-task targets aren’t improving GHI.  

- **Hypothesis 5: Advanced sequential models (Transformers, TCNs, State-space).**  Modern sequence-to-sequence architectures can capture complex temporal patterns.  The Temporal Fusion Transformer (TFT) and related models use attention to focus on relevant time lags, and have achieved strong results in solar forecasting.  For example, a TFT augmented with variational mode decomposition (VMD) outperformed ANN, LSTM, CNN–LSTM, and vanilla transformer models.  This suggests POLARIS might gain by replacing its current model (likely a tree or simple net) with a TFT or a temporal convolution network.  These models use only existing inputs at t₀, but process them with richer memory.  Expected gain is **small-to-moderate** (maybe a few % of nMAE) since they mainly improve feature usage rather than add new information.  Difficulty is **high** (complex architecture, heavy tuning).  Data-risk and leakage: none.  An experiment is to train a TFT-based model on the existing features and compare its forecast error to the current champion; a failure to improve would refute this as a game-changer.  

# Top 3 experiments

1. **Satellite image forecasting vs baseline.** Implement a deep CNN (e.g. U-Net) that takes several past minutes/hours of satellite cloud-index images as input and predicts next-hour irradiance at the site (optionally via predicting future CI maps).  Compare its nMAE on ODD test data to the Stage 7.5 champion.  A significant drop (e.g. >5% absolute nMAE) would support the satellite-nowcasting hypothesis.  

2. **Clear-sky residual model.** Compute a clear-sky GHI time series (using a validated model) for all training dates. Train a regression model (e.g. gradient boosting) to predict the **deviation** of observed GHI from clear-sky, using the same features as the champion.  Then combine the clear-sky and predicted residual.  Evaluate if the combined forecast beats the champion’s MAE.  If error shrinks substantially, it confirms the physics-guided approach.  

3. **Regime-specialized models.** Define 2–3 regimes (for example: *“sunrise/sunset ramp”*, *“clear day”*, *“broken clouds”* based on initial cloud cover or variability in the first hour). Train separate models for each regime using only the subset of training examples. At test time, use the appropriate model for the regime at t₀ (e.g. from a threshold on current sky-view factor or recent variability).  If the mixture outperforms the single-model champion, it indicates regime-switching helps.  

# Recommended first experiment

**Implement the clear-sky baseline + residual approach.** This is relatively easy and isolates the impact of known physics.  Specifically, use an established clear-sky model (e.g. McClear or Bird) to compute *GHI<sub>clear</sub>* at each timestamp. Define *CSI = GHI<sub>obs</sub>/GHI<sub>clear</sub>*. Train an ML model to predict CSI (or equivalently the residual *GHI<sub>obs</sub> – GHI<sub>clear</sub>*) for H1–H24 using the same inputs as the champion. Combine the forecast CSI with the known GHI<sub>clear</sub> to get a final GHI forecast.  Compare its daytime nMAE to the champion.  This test uses only existing data and directly validates whether separating out the deterministic component helps. If this experiment fails to reduce error, it suggests more radical changes (like new data sources) are needed.  

# Why previous approaches failed to reach <15% nMAE

The dominant source of error is **cloud variability and motion**, which is extremely hard to predict from the current inputs.  As noted by Straub et al., solar forecasts are limited by “aperiodic events, primarily the occurrence of clouds”.  POLARIS’s current inputs (e.g. NWP cloud fields, local weather, topography) cannot fully resolve *when and where* small clouds will appear or disappear.  Without a direct cloud-observation input (satellite or camera) or a specialized physics model for cloud attenuation, the ML model is essentially guessing.  High-latitude sites also have extreme seasonal variations (persistent low sun, rapid weather changes), so a single model struggles to cover all cases.  In summary, existing methods likely hit a **cloud-forecast ceiling**: they model the smooth diurnal cycle well but cannot capture the rapid irradiance ramps caused by broken clouds.  This inherent unpredictability explains why nMAE has plateaued around ~28% despite incremental model refinements.  (This aligns with the literature: “[R]apid weather-related fluctuations” remain poorly represented by both pure physics and pure data methods.)  

# Is <15% nMAE plausible with available data?

Dropping from ~28% to <15% is a **very large** jump.  With only the current data (NWP fields, past irradiance, terrain/horizon, etc.), it seems unlikely.  Most gains now must come from *new information*, especially about clouds.  If POLARIS were allowed high-resolution real-time cloud observations (satellite CI, sky images, cloud lidar) or additional physics (aerosol optical depth, radiative transfer), reaching 15% might be possible.  In practice, state-of-the-art solar forecasts that do use satellite nowcasting can achieve much lower errors on short horizons; for example, HelioNet’s irradiance forecasts were ~8% lower RMSE than a standard cloud-tracking baseline.  This suggests *some* improvement is achievable.  However, for the full 24‑hour horizon at a polar station, achieving <15% would likely require an *ensemble* of the above breakthroughs (cloud imagery, physics priors, specialized models).  Without such additions, hitting <15% seems optimistic.  

# Requirements to approach ≤10% nMAE

Reaching the extreme goal of ~10% would probably demand **radical new capabilities**.  For example, continuous all-sky cameras or ceilometers at the station could capture cloud changes on <1‑min scales (all-sky imagers have achieved <10% error in minute-ahead forecasts).  Satellite data would need to be fused with very high spatial/temporal resolution (e.g. polar-orbit imagery or radar).  Physically, one might incorporate full radiative-transfer models that use detailed NWP outputs (aerosols, humidity profiles) rather than learning from coarse proxies.  In ML terms, an ensemble or hierarchical system (cloud model + clear-sky model + regime models) would be necessary.  All these would require substantial new data and complexity; under current constraints, 10% appears out of reach. 

**If we had to bet on one remaining mechanism** causing most error, it would be *unresolved cloud dynamics (rapid advection and formation/dissipation)*.  If we could observe or predict that causally at t₀ – for example, via the latest satellite cloud mask and motion vectors over the station – we might greatly reduce error.  A clean experiment is to add just the current satellite-derived cloud index (or next-satellite-imagery forecast) into the model: if doing so dramatically cuts nMAE, it confirms that cloud information was the missing piece.  

**Sources:** Recent solar‐forecasting literature on cloud-index/Heliosat methods, and on physics-informed residual models, among others, inform these hypotheses. These point to cloud prediction and clear-sky decomposition as the most promising paths.
